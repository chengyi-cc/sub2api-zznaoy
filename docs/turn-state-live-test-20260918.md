- Team 332 与 Pro 292 独立，拒绝各自不合格长度及跨规则使用。
- 原 Pro 缓存可在明确选择 Pro＋IPv6 池后兼容使用。

- 连续失败计数跨轮次保存，第三次失败后切换国家，成功后清零。
- 并发与账号模型隔离、关闭或切换设置期间不发布旧任务结果。
- 购买代理同连接来源核验、IPv4 检查、国家检查、共享地址去重、只取头部不等待完整生成。
- 原 IPv6 加密代理采集及退役链路。
- 页面 Team/Pro 和出口选择的保存、剩余有效期倒计时、按需显示历史且不显示原始状态。

这些结果不保证候选国家永远有效，也不保证其他账号或模型具有同样命中率。可用状态仍需逐个采集，国家轮换是失败恢复策略。
