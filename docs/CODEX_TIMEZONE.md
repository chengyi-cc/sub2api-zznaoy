# 时区与日期改写

账号编辑窗口的「时区与日期改写」大开关位于模板栏与「Excel / BPS 协议」之间。适用于 OpenAI 直接 OAuth（登录授权）账号，默认关闭，与 Excel 通道开关独立；不增加检测功能。

- 开启后，按账号代理出口查询时区；没有代理则使用服务器直连出口。采用参考文档的 30 个允许时区，查询失败或结果不在列表内时回退为 Asia/Singapore（新加坡）。
- 只修改用户消息中以 `<environment_context>`（环境信息块）开头的文本，将首个 `<timezone>` 改为目标时区，首个标准 `<current_date>YYYY-MM-DD</current_date>` 改为该时区的当天日期。保留不可用日期、自闭合标签、普通正文及工具内容。
- 支持普通请求、自动透传、Excel / BPS 和 WebSocket（双向长连接）的首轮与后续轮次。不修改服务器时间，也不改小时、分钟或秒。
- 关闭时不查询出口，不改写请求。已有账号没有设置值时也保持关闭；后台保存标记为 `extra.openai_codex_timezone_rewrite=true`，关闭时移除标记，无数据库迁移。
- 每个代理出口的成功查询在服务进程内缓存 24 小时，失败缓存 10 分钟；同出口并发共享查询，最多保存 1024 项。重启会清空该缓存。
- 首次查询使用 `https://ipinfo.io/json`，最多等待 3 秒，只发送出口查询，不发送用户对话或模型登录凭据；失败使用新加坡继续处理。命中缓存后不重复查询。
- 改写内容在同一时区、同一天保持稳定；开启开关、跨日期或出口时区变化会改变请求环境文本，可能影响上游提示词缓存命中。不会额外调用模型。

规则来源：用户提供的 `2026-09-24-codex-inspector.public.md`，采用其默认出口时区策略；不引入插件、随机时区、额外检测或配置页面。
