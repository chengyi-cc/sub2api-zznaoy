# OpenAI 账号设置模板

新增 OpenAI 账号默认使用“关闭（不收敛）”，保持客户端原始设备与会话标识。既有账号设置不自动改动；在表单或模板里明确选择其他收敛模式后才启用。

OpenAI 账号新增、编辑窗口顶部显示“修改模板”和“一键应用模板”。模板通过管理员接口保存到服务器，换浏览器也可使用。保存模板只保存模板本身；应用模板填入当前表单，之后通过原账号保存/导入流程生效。

模板编辑器支持逐项勾选覆盖，每个未勾选项保留原表单值。已勾选项支持明确设置为关闭、清空代理、清空分组或清空映射；不会因值为 false、null 或空列表而忽略。取消编辑不会保存；“从当前表单读取已选项”便于复用正在编辑的设置。

覆盖范围包括并发数、负载系数、优先级、计费倍率、代理、分组、到期暂停、指纹收敛、TLS（连接握手特征）、WebSocket（持续连接方式）、透传、客户端限制、工具调用兼容、长上下文计费、压缩能力及映射、模型白名单和映射、接口能力、号池重试与 API Key（接口密钥账号）的额度上限。按账号类型显示适用项；编辑一类账号的模板时保留另一类账号专用字段。

账号名称、身份凭据、令牌、密钥、运行状态不纳入模板。后端使用允许字段清单、类型与范围校验，拒绝任意账号字段或凭据字段。模板总大小最多 64 KiB。模型列表等可变值在应用时复制，避免表单后续修改反过来污染模板。

管理员接口：`GET/PUT /api/v1/admin/settings/openai-account-template`。设置键为 `openai_account_form_template_v1`；版本字段为 1，无模板时返回空字段集合。

自动化验证包括默认不收敛、模板保存与未勾选删除、关闭/清空的语义、账号类型隔离、模型白名单模式切换、取消与迟到响应，以及实际新增导入和编辑提交时保留未选设置与账号身份。
