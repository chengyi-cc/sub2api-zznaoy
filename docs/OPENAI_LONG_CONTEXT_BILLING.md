# GPT-6.1 Sol 订阅长上下文附加费开关

入口：管理员 → 系统设置 → 网关 → **GPT-6.1 Sol 订阅长上下文免附加费**。修改后点击保存。

- 默认关闭，包括升级前没有保存过此字段的站点。按原有账号、分组及价格设置计费；关闭免除开关不会强行开启原本关闭的长上下文加价规则。
- 开启后，仅实际使用 GPT-6.1 Sol 的 OpenAI 登录授权或订阅访问令牌账号免除模型价卡中的长上下文附加费。客户模型别名按实际发送到上游的模型判断，影子账号按实际凭据所属的母账号判断。
- API Key（上游接口密钥）账号不享受该豁免。自定义价格区间、分组倍率和优先处理费用继续生效。
- 这控制本系统的扣费和账号成本统计，不改变第三方上游账单。GPT-6.1 Sol 的 500k 默认上下文窗口不受这个开关影响。
- 使用现有设置表，无新增数据库迁移。后台管理接口字段为 `openai_gpt61_sol_long_context_exemption_enabled`（是否启用免附加费）；省略字段时保留原值，显式 false 关闭。缺失、非法或无法读取的配置均不启用豁免。
- 每次符合模型及账号条件的计费读取一次当前设置，并将结果用于该次扣费、重新定价和账号成本计算。保存后下一次计费即按新值处理，不缓存旧开关值，不追溯修改历史账单。

代码更新需要重新构建并更新前后端，现有线上版本不会仅因推送源码自动变化。
