# 首页设计方案与六款随机主视觉

## 已确定：正常模式 12 深蓝，暗黑模式 15 雾银

优先打开 `../../frontend/public/homepage-concepts/selected-home.html`（与正式首页共用组件的定稿本地预览）。点击右上角月亮或太阳切换主题；也可切换中英文。预览无需后台服务，不修改线上设置，业务入口仅作为目标路径展示。

- 正常模式沿用 12 的深蓝配色、开放式首屏和三项配置条；暗黑模式沿用 15 的分块布局与雾银材质，并将原来的雾白底调整为石墨深底，减少夜间亮度。此映射遵循已选方案，不会因为深蓝看起来像暗色就反转编号。
- 首屏左右比例约 51:49，内容宽度上限 1248 像素；正文 16 像素、按钮与导航 14 像素，标题按屏幕缩放。采用系统中文无衬线字体，不额外下载字体文件。小屏改为单列，主视觉保持透明无框。
- `DesignedHome.vue`（正式首页的双主题界面组件）取代默认展示页；自定义首页设置仍优先，其次是精简首页，未启用这两者时才显示新首页。不需要把静态片段粘贴到后台。
- 站点名称、标志、副标题、文档地址、模型广场开关和登录状态均读取原设置；普通用户、管理员与未登录访客使用原有入口。不展示虚构的在线统计、速度或免费额度。
- `useSiteTheme.ts`（复用现有主题存储与全站暗色标记的状态管理）沿用 `theme`（浏览器保存的主题选择）和根元素的 `dark`（全站暗色样式标记）。支持恢复偏好、系统主题、跨标签同步及其他页面修改主题，并在离开首页时清理监听。
- 切换主题只改变页面布局、配色和文案，不重建主视觉，不重新随机，不重置当前角度或暂停状态。每次重新进入首页仍随机选择六款之一。
- `home-artwork.css`（生成到应用内的共享图形样式）与静态方案共用同一来源；`home-artwork-fallback.svg`（加载交互前的静态后备图形）避免空白。原 01–15 方案仍保留作历史对照。
- `build-selected.mjs`（定稿预览打包脚本）打包实际组件，生成可直接本地打开的预览，不另维护一套页面实现。运行下方原生成命令会同时更新全部预览。

本次改动仅在本地源代码与预览文件中完成，尚未部署线上。浏览器自动化连接当前受认证方式限制，尚未进行真实浏览器截图与不同宽度下的目视验收；自动检查不等同于视觉验收。

## 本次：主视觉确定，重新选择页面风格

优先打开 `../../frontend/public/homepage-concepts/page-styles.html`（新五套完整页面的本地对比入口）。本次只沿用已认可的右侧雕塑，不沿用 05 的整页黑金编辑风格。

### 鼠标交互与更明显的动效

- 打开页面直接开始持续的空间旋转，不再开场漂浮或等待。横向约 40 秒转一圈，同时有轻微纵向翻转；透明背景和六款随机保持不变。
- 点击图形向右转 32 度；按住鼠标左右拖动绕竖轴旋转，上下拖动调整俯仰，松手有不超过 0.7 秒的衰减惯性。两个方向均可连续多圈旋转，已删除原来的上下正负 65 度限制。
- 鼠标操作不再显示包围图形的外框。键盘焦点改为下方操作文字的颜色与下划线提示，不再圈住图形。
- 用户开始操作时立即暂停自动展示，手动旋转和惯性结束后静置约 2.4 秒，再从当前角度继续自动旋转，不抢夺拖拽控制。“复位”恢复原始角度并直接继续旋转。
- 图形下方提供“复位”，恢复原先认可的精确初始图形。键盘方向键每次转 15 度，按住 Shift（加大步幅的组合键）时转 30 度；Home（回到初始位置的按键）或 Escape（取消键）可复位。
- 手机支持横向拖动，竖向手势留给页面滚动。交互使用 Pointer Events（统一处理鼠标、触摸和触控笔的事件），拖出图形边界也能正常结束，不会卡在按住状态。
- 用户暂停动效或系统开启“减少动态效果”时，关闭自动动画、点击缓动和松手惯性，但仍能主动点击、拖动和复位。页面隐藏或图形滚出可见区域时停止自动绘制；在预览室内点击外侧按钮不会因内嵌页失焦而停转；重新可见后再继续，离开首页时清理计时器、动画、可见区域观察和事件。
- `homeArtworkRenderer.ts`（根据空间坐标重新计算屏幕线条的绘制模块）会同步更新图形、中心标记和中心前后遮挡，不是把一张平面图片倾斜。追加五款使用原有空间坐标；原版椭圆按现有投影轮廓补充深度，静止后备图和复位仍精确保留原版。线框采用简化层次排序，不是完整实体表面深度渲染。
- `homeArtworkInteraction.ts`（自动旋转、点击、拖动、惯性和清理逻辑）由正式首页、独立网页和预览室共享。旋转随浏览器每次画面刷新更新，不再人为限制到约每秒 20 帧；复用图形元素，只更新坐标等变化的属性，不再逐帧重建整张图。每帧共用旋转系数，中心之外不会显示的前景线段不再重复输出，减少持续旋转的绘制开销。
- 预览室从父页面为内嵌预览绑定交互，仍不开放预览框内部脚本权限；五款对比缩略图只用于选款，请进入单款预览后拖动。后台片段继续无脚本，需要部署本次前端更新才能获得原生交互支持。

## 为什么可以直接换首页

项目已经有 `home_content`（管理员配置的自定义首页内容）。`frontend/src/views/HomeView.vue` 的渲染顺序是：

1. 自定义内容非空且以 `http://` 或 `https://` 开头：用 iframe（网页内嵌窗口）展示该网址。
2. 自定义内容非空但不是网址：用 `v-html`（将配置内容插入页面的 Vue 指令）展示 HTML（网页结构代码）。
3. 没有自定义内容：显示现有简洁首页或默认首页。

这些方案走第二条：粘贴网页结构和内联样式。首页片段没有 JavaScript（执行交互逻辑的脚本），常见问题由浏览器原生折叠组件实现。01–10 静态片段不需要应用更新；11–15 的随机图形由本次新增的原生首页代码处理，不依赖 `v-html` 执行脚本，也不放宽脚本安全设置。

你提供的三个参考域名的首页响应都能读取到公开站点配置，当次读取的 `home_content` 为空；这说明不能仅凭外观断言它们是“后台贴 HTML”。可能使用源码定制等方式，未检查其完整运行页面与实现，不作确定归因。

## 选定后如何上线

1. 先备份后台现有的“自定义首页内容”，也记录原来的简洁首页开关状态。
   选择 11–15 时，先按照项目原有流程构建并部署本次前端更新；只上传本地预览文件不能更新正式首页的随机功能。
2. 在本地预览中选定方案、确认站点名称，点击“导出所选方案” → “复制后台代码”。
3. 到管理后台的系统设置 / 站点设置区域，找到“自定义首页内容”输入框（字段名 `home_content`），粘贴并保存。
4. 访问站点 `/home`（现有首页地址），分别检查电脑和手机端；点击控制台按钮验证登录后的跳转。
5. 如果需要恢复，填回备份内容；原本内容为空则清空后保存，现有首页会重新接管。

注意：粘贴的是后台片段，不是预览室的 `index.html`，也不是那个文件的本地磁盘路径。

现有业务链接为 `/dashboard`（用户控制台）、`/keys`（访问密钥管理）、`/key-usage`（密钥用量查询）。静态片段不自动读取登录身份、站点语言、后台名称或动态价格；更改站点设置不会自动改这段代码。若希望管理员与普通用户分流、自动跟随站点设置或多语言切换，选定视觉后再改成 Vue 组件（项目原生的可交互页面模块）。

## 上线前需确认

- 站点名称和正式标志。当前暂按截图的 `zz.naoy` 制作。
- 实际开放模型、分组与计费规则。页面对模型生态和终端配置均标注为示例，未编造在线率、延迟、用户数量或优惠价格。
- 必要的客服、文档、隐私与服务条款入口。这次未擅自编造这些地址。
- 不要在自定义 HTML 中放真实密钥、密码或其他私密资料，内容会公开给访问者。
- 当前样式限定在 `hc-`（旧首页方案样式前缀）或 `hf-`（新页面风格样式前缀）范围内；部署环境若自定义了 CSP（浏览器内容安全策略），仍需验证是否允许内联样式。
- 01–10 静态片段无需重编译；11–15 的随机功能需要部署本次前端更新。若把预览目录随前端一起构建发布，它将成为可公开访问的静态资源；后台粘贴方式不依赖这些预览文件。
